작은 GPU, 언제 더 저렴할까?

GPU는 켜 둔 시간에, Sonic은 처리한 토큰에 비용이 발생합니다. 같은 길이의 차량 명령을 기준으로 월 사용량과 필요한 서버 시간을 비교합니다.

이번 시험의 선택

모델 정확도와 동시 요청 시험을 진행하고 있습니다.

운영 가정

730시간은 365일 × 24시간 ÷ 12개월인 월평균 상시 실행 시간입니다. 요청 없이 대기하는 시간도 포함합니다. 실제 30일은 720시간, 31일은 744시간이며 재시작 시 모델 준비 시간이 필요합니다.예: 추가 서버 2대를 각각 100시간 실행하면 200시간.기본값은 새 세션의 한국어 합성 음성 1건 실측입니다. 입력 5.12초·응답 3.04초. 긴 대화, 침묵, 툴 호출에 따라 달라집니다. Sonic의 한국어는 공식 지원 언어가 아니므로 품질 동등성 가정은 아닙니다.

읽는 방법

사용량이 적으면 GPU 대기 비용이 커서 Sonic이 저렴합니다. 사용량이 늘어도 GPU 대수가 그대로면 오픈 모델이 유리해질 수 있습니다. 서버를 추가하면 고정비와 손익분기점도 함께 올라갑니다.

손익분기점은 처리량 보장이 아닙니다. 아래 실측에서 정확도와 지연을 지키는 서버 용량을 확인한 뒤, 필요한 복제본 수를 위에 입력해야 합니다. 모델 점수는 음성 자연스러움 점수가 아닙니다.
